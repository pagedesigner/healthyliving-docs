# EMR

The EMR area is used by clinical and operations staff to manage patients, orders, subscriptions, questionnaires, prescriptions, consultations, and fulfillment-related workflows.

## Common Tasks

- Search and review patient records
- Review orders and current order status
- Assign or review intake questionnaires
- Manage subscription-related clinical changes
- Submit or retry pharmacy/integration actions
