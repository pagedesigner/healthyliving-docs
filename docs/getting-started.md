# Getting Started

Healthy Living Portal Docs explain the main workflows for staff, administrators, and operators.

Use these guides for:

- EMR workflows
- Patient portal workflows
- CRM workflows and automation
- Intake forms and questionnaire requirements
- Orders and subscriptions
- Monitoring and troubleshooting

Do not add real patient data, passwords, tokens, or private operational secrets to public documentation.
