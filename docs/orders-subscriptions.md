# Orders and Subscriptions

Orders and subscriptions connect checkout, recurring billing, intake requirements, payment status, and fulfillment workflows.

## Order Payload Fields

Useful workflow fields include:

- `order.status`
- `order.source`
- `order.subscriptionId`
- `order.intakeRequired`
- `order.intakeSubmitted`
- `order.pendingFormIds`
- `payment.status`
- `subscription.status`

## Subscription Events

Subscription-related workflows can be triggered by subscription creation, renewal order creation, pause, cancellation, activation, and upcoming renewal events.
